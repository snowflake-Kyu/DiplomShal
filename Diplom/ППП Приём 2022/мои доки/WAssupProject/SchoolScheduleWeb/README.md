# SchoolScheduleWeb

ASP.NET Core MVC веб-приложение для просмотра расписания занятий через готовый API.

## Назначение

Приложение не подключается напрямую к базе данных. Оно работает как веб-клиент и получает данные через HTTP API.

Используются API-разделы:

- `GET /api/schedules`
- `GET /api/schoolclasses`
- `GET /api/disciplines`
- `GET /api/timeslots`
- `GET /api/teachingassignments`
- `GET /api/teachers`
- `GET /api/auditoriums`

## Порты

- API должен быть запущен на `http://localhost:54040`
- Веб-приложение запускается на `http://localhost:54041`

Так сделано специально, потому что API и сайт не могут одновременно занимать один и тот же порт.

## Настройка адреса API

Адрес API находится в файле `appsettings.json`:

```json
"ApiSettings": {
  "BaseUrl": "http://localhost:54040/api"
}
```

Если API запущен на другом порту, поменяйте значение `BaseUrl`.

## Запуск

Сначала запустите API:

```bash
dotnet run
```

Затем в отдельном терминале запустите веб-приложение:

```bash
dotnet restore
dotnet run
```

Откройте в браузере:

```text
http://localhost:54041
```

## Что есть в интерфейсе

- просмотр общего расписания;
- отображение даты, дня недели, времени, класса, дисциплины, преподавателя и аудитории;
- фильтр по дате;
- фильтр по классу;
- фильтр по дисциплине;
- фильтр по преподавателю;
- текстовый поиск;
- страница подробного просмотра записи расписания.
